# 补植验收册数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 街段验收单 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 验收日、观察期天数、单株款元、逐株事件 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

事件写 `树号:日期:种植或死亡或补植或巡检存活`。验收日之后的状态不参与本批。

补植从当天重置观察期；巡检日距补植达到期间要求才算通过。按唯一树号结算，款项按分取半入。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `街段验收单` 和 `外部记录值(元)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **元**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。

## 分期签收与差额结算

签收按期登记，期号为 `YYYY-MM`。每期对每个业务键给出 `已付`、`应付` 与 `差额 = 应付 - 已付`：差额为正记 `补付`，为负记 `扣回`，为零记 `结清`。只有差额签收后才计入 `已付`；无差额的键只登记 `结清`，不生成款项。

- 应付取该键当前最高修订的可采信复算金额。隔离或被阻断的键记 `待核`，不签收也不计入已付；若该键此前已有签收，其已付金额在 `已付待核` 中列出，等来源补正后再结差额。
- 修订或补交的验收单改变应付金额时，不动旧签收记录：旧签收保留当时的金额、已付基数、应付额与修订号，差额落到下一期核对。未显式指定期号时，新出现的业务键计入本批次所属月份，已签收过的键计入其最后签收期号的次月，因此补交后自动进入下一期而非重开旧期。
- 已按某修订签收后，重开旧批次不会反向补付：低修订的批次记 `STALE_REVISION`，只保留旧签收留痕，等新修订在下一期结出差额。
- 签收记录按 `业务键 + 期号` 幂等。相同批次重复签收或复算重试只返回跳过，不重复补付或重复扣回。
- 显式倒签到已签收期号之前的期，或把下一期的差额强行记到旧期，会被拒绝（`PERIOD_ORDER`）。已签收的键若不在当前对账范围内，其已付金额在 `孤儿已付` 中列出，供下期核对是否应扣。

| 接口 | 用途 |
|---|---|
| `GET /api/settle/{run_id}?period=YYYY-MM` | 预览应补、应扣、结清与待核 |
| `POST /api/settle/{run_id}` `{period,note}` | 签收差额，返回本期签收与跳过明细 |
| `GET /api/settle/{run_id}/signoffs` | 该批次关联的签收记录（含旧期） |
| `GET /api/settle?period=YYYY-MM` | 按期查询签收台账 |
